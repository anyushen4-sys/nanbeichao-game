# Steam Screenshots

## Requirements
- **Minimum**: 5 screenshots, **Recommended**: 8+
- **Format**: JPG or PNG
- **Resolution**: ≥ 1920×1080 (Steam recommends 16:9)
- **Content priority**:
  1. Battle scene (three-line battlefield with cards)
  2. Leader selection screen
  3. Card detail (one of the 63 generals)
  4. Combo/counter animation trigger
  5. Victory/defeat screen
  6. Tutorial/intro sequence
  7. Settings/menu UI
  8. AI difficulty selector

## Capture Guide (from CAPTURE_GUIDE.md)
See `CAPTURE_GUIDE.md` in this directory for detailed tips on:
- Best lighting/composition
- Avoiding UI clutter
- Showcasing ink-wash art style
- Highlighting faction colors and card abilities
