# 《南北朝·天下对弈》— 简体中文 · 官方发布说明

> 一局南北，半部中国史。

**南北朝·天下对弈** (Nan-Bei Chao: War of Dynasties) 是一款以中国南北朝时代为背景的单机策略卡牌游戏。九位历史领袖逐鹿中原，63 位青史武将纵横驰骋，水墨古风画境，每一局都是新的南北之争。

---

## 核心玩法

- **三行战场**: 步兵 / 骑兵 / 水军，各自计算战力，最终以「剩余战力」判胜负
- **9 位历史领袖**: 刘裕、萧道成、陈霸先、宇文泰、拓跋焘、高欢、宇文邕、高洋、段韶，每位有独特阵营基调与被动技能
- **63 位武将**: 宋齐梁陈、北魏东魏西魏北齐北周，全部基于史实考据
- **卡牌组合系统**: 同阵营 ≥3 张触发 combo，反制牌可减益敌方阵营
- **三种难度**: 新学 / 中坚 / 大师，AI 会算牌、识破换牌、把握过牌窗口

## 游戏模式

- **AI 对战**: 单人挑战，随机主将，三局两胜
- **同机对战**: 好友共屏轮流操作
- **多人模式**: 网络联机对战 (开发中)

## 美术风格

水墨古风 + 暖色调 + 古典字体。所有卡面插画为 AI 辅助生成的水墨武将风格，色调以赭石、藤黄、墨黑为主，辅以阵营主色高光。

## 系统需求

**最低配置:**
- 操作系统: Windows 10 (64-bit)
- 处理器: Dual-core 1.6 GHz
- 内存: 4 GB RAM
- 显卡: Intel HD 4000 or equivalent
- 存储空间: 500 MB

**推荐配置:**
- 操作系统: Windows 11 (64-bit)
- 处理器: Quad-core 2.0 GHz 或更高
- 内存: 8 GB RAM
- 显卡: 独立显卡
- 存储空间: 500 MB

## 技术说明

- 基于 Electron 桌面应用，Windows 平台
- 集成 Steamworks SDK (成就 / 统计)
- 支持 12 种 UI 字体缩放比例
- 背景音乐由 Pixabay 授权曲库提供
